# Nasdaq Sentinel

Bot educativo de análisis técnico del futuro del Nasdaq.

Funciones previstas:

- Análisis de la sesión de Nueva York.
- Medias EMA20 y EMA50.
- RSI y ATR.
- Máximos, mínimos y equilibrio de la sesión.
- Detección de FVG.
- Zonas simuladas de entrada, stop y objetivos.
- Alertas privadas mediante Telegram.

Este proyecto funciona exclusivamente en modo educativo y simulado.
No ejecuta operaciones ni constituye asesoramiento financiero.
